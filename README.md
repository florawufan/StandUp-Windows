# StandUp Windows

A lightweight Windows sitting reminder tool written in VBScript.

一个简单的 Windows 久坐提醒工具，使用 VBScript 编写。

## Features / 功能

-  Remind users to stand up regularly
-  Lightweight and easy to use
-  No installation required

## Usage / 使用方法

1. Download `StandUp.vbs`
2. Double click the file
3. Keep it running in the background
